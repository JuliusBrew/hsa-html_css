# 0x01 – HTML Foundations

> Structure comes before style.

In this module you will learn how to properly structure content using HTML.  
You will move from basic elements to writing clean, semantic, and accessible markup.

## Learning Goals

- Write valid HTML5 documents
- Understand elements, tags, and attributes
- Use headings in the correct hierarchy
- Format text properly
- Apply semantic HTML (`header`, `main`, `section`, `article`, `footer`, etc.)
- Follow basic accessibility good practices
- Build small, well-structured pages

## Topics

- HTML Document Structure (boilerplate)
- Elements, Tags, and Attributes
- Headings and Text Formatting
- Semantic HTML
- Basic Accessibility (alt text, heading order, language attribute)
- Comments and code organization

## Submission Instructions

1. Create the folder `0x01-html_foundations` in your `html_css` repository.
2. Add all the required files listed above.
3. Complete the `CHECKLIST.md`.
4. Test every HTML file in the browser.
5. Push to GitHub and submit your repository link.

## Important Rules

- Use the exact filenames given.
- Write clean, properly indented code.
- Use semantic elements whenever they make sense.
- Every page must contain the correct HTML5 boilerplate.
- Content should be original (do not simply copy examples).
