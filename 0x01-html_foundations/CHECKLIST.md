# 0x01 – HTML Foundations | Checklist

Complete every item before submitting.

---

### General Requirements (All HTML Files)

- [ ] Has `<!DOCTYPE html>`
- [ ] Has `<html lang="en">`
- [ ] Has `<meta charset="UTF-8">`
- [ ] Has viewport meta tag
- [ ] Code is cleanly indented
- [ ] File opens correctly in the browser
- [ ] Filename is exactly as required

---

### 0-boilerplate.html

- [ ] Contains the full correct HTML5 boilerplate
- [ ] Has a meaningful `<title>`
- [ ] Contains at least one heading and one paragraph inside `<body>`

---

### 1-headings.html

- [ ] Contains one `<h1>`
- [ ] Contains at least two `<h2>`
- [ ] Contains at least two `<h3>`
- [ ] Heading levels follow a logical order (no random skipping)

---

### 2-text_formatting.html

- [ ] Uses at least three different text formatting tags (e.g. `<strong>`, `<em>`, `<mark>`, `<small>`, `<del>`, `<ins>`, `<sub>`, `<sup>`, etc.)
- [ ] Contains a paragraph that mixes normal text with formatted text
- [ ] Code is properly nested

---

### 3-semantic_page.html

- [ ] Uses `<header>`
- [ ] Uses `<main>`
- [ ] Uses at least one `<section>` or `<article>`
- [ ] Uses `<footer>`
- [ ] Page has clear structure and enough content to look complete

---

### 4-accessibility_basics.html

- [ ] Uses proper heading hierarchy
- [ ] Contains at least one image with a meaningful `alt` attribute
- [ ] Sets the page language with `lang="en"`
- [ ] Contains at least one descriptive link (not “click here”)
- [ ] Shows basic awareness of accessibility good practices

---

### 5-blog_article.html

- [ ] Content is wrapped in an `<article>`
- [ ] Has a clear title (`<h1>`)
- [ ] Includes author or date information
- [ ] Uses at least two subheadings (`<h2>`)
- [ ] Contains multiple paragraphs of real content
- [ ] Uses semantic structure (`header`, `footer` inside the article recommended)

---

### Mini Project: mini-project-profile_page.html

- [ ] Correct HTML5 boilerplate
- [ ] Clear main heading (name or title)
- [ ] Uses semantic elements (`header`, `main`, `section`/`article`, `footer`)
- [ ] Contains multiple content sections (About, Skills, Interests, Contact, etc.)
- [ ] Includes at least one image with proper `alt` text
- [ ] Looks like a complete, well-structured personal profile page
- [ ] Code is clean and readable
