# 0x00 – How the Web Works

> Before you write a single line of HTML, you must understand what happens when a user types a URL and presses Enter.

This module gives you the essential mental model for everything that follows in web development.  
By the end, you will understand the full journey of a web request and how browsers turn code into pages.

## Learning Goals

- Explain the Client–Server model clearly
- Understand IP, TCP/IP, and DNS at a practical level
- Break down the parts of a URL
- Describe how browsers request and render pages
- Explain what the DOM is
- Distinguish Frontend from Backend
- Use Chrome DevTools (Elements + Network tabs)
- Correct common beginner misconceptions about how the web works

## Topics

- Client–Server Model
- IP Addresses & TCP/IP (simplified)
- DNS
- Understanding URLs
- How Browsers Request Pages
- How Browsers Render Pages
- The DOM
- Frontend vs Backend
- Chrome DevTools (Network + Elements)
- Common Misconceptions
